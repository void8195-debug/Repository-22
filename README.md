# BouncyBall: удалённое управление

Схема простая: **сервер-ретранслятор** (этот `server.js`) лежит в интернете. Программы `BouncyBall.exe`
на компьютерах друзей сами подключаются к нему (исходящее HTTPS, ничего пробрасывать на роутере не нужно)
и ждут команд. Ты открываешь **пульт** (веб-страницу самого сервера) в браузере, на телефоне или на компе,
нажимаешь кнопку, и сервер передаёт команду всем программам в твоей «комнате».

```
 пульт (браузер) ──HTTPS──▶  server.js  ◀──HTTPS (долгий опрос)── BouncyBall.exe у друга
```

## 1. Запустить сервер

Нужен Node.js 18+ (зависимостей нет). Два обязательных значения:

* `ADMIN_TOKEN`: твой пароль администратора (от 8 символов, придумай длинный). Он нужен только для отправки команд.
* **Ключ комнаты** придумываешь сам (8-64 символа: буквы, цифры, `_`, `.`, `-`), например `moi-druzya-2026-x7k2`.
  Его знают программы друзей и ты. Комнат может быть сколько угодно, они создаются сами.

### Вариант А. Быстрая проверка у себя на ПК (бесплатно, без аккаунтов)

```
set ADMIN_TOKEN=придумай-длинный-пароль
node server.js
```
(в PowerShell: `$env:ADMIN_TOKEN="..."; node server.js`)

Во втором окне открой публичный адрес через Cloudflare Quick Tunnel:
```
cloudflared tunnel --url http://localhost:3000
```
`cloudflared` напечатает адрес вида `https://что-то-случайное.trycloudflare.com`: это и есть адрес сервера.
Минусы: адрес меняется при каждом запуске, а пока твой ПК или окна выключены, управлять нельзя.
Подходит, чтобы попробовать.

### Вариант Б. Постоянный бесплатный сервер (Render.com)

1. Загрузи папку `server` в репозиторий на GitHub (файлы `server.js`, `package.json`).
2. На render.com: **New → Web Service**, выбери репозиторий. Build command: `npm install`, Start command: `node server.js`, тариф Free.
3. В разделе Environment добавь переменную `ADMIN_TOKEN` со своим паролем.
4. Через минуту появится адрес `https://имя.onrender.com`. Это адрес сервера, TLS уже включён.

Особенности бесплатного тарифа: если 15 минут нет запросов, сервис «засыпает», а просыпается примерно за минуту.
Пока хотя бы одна программа онлайн и опрашивает сервер, он не спит. Программы при обрыве сами переподключаются.
Render может перезапускать бесплатные сервисы в любой момент: тогда команды, отправленные в эту секунду, пропадут.
Условия тарифа могут меняться, проверь на сайте.

### Вариант В. Свой VPS
Скопируй папку, запусти `ADMIN_TOKEN=... PORT=3000 node server.js` под `pm2` или `systemd`, поставь перед ним
nginx или Caddy с HTTPS. Программа ходит и на обычный `http://`, но для интернета нужен HTTPS.

## 2. Настроить программу у себя и у друзей

В `%APPDATA%\BouncyBall\settings.ini` (или в файле `remote.ini` рядом с exe) должно быть:

```
[remote]
url=https://имя.onrender.com
room=moi-druzya-2026-x7k2
```

Проще всего: ПКМ по мячу или по иконке в трее → **Удалённое управление → Настройки…** (откроется Блокнот).
Для друзей можно просто положить рядом с `BouncyBall.exe` готовый файл `remote.ini` (шаблон: `remote.ini.example`).

Потом **Удалённое управление → Включено**. Программа покажет окно с объяснением, что именно можно делать удалённо,
и включится только после «Да». В подсказке иконки в трее будет написано «удалённое управление ВКЛ». Выключить можно
в любой момент тем же пунктом меню.

## 3. Пульт

Открой адрес сервера в браузере. Введи ключ комнаты и пароль администратора (запоминаются в браузере).
Вверху покажет, сколько программ онлайн. Кнопки: подбросить все, добавить/убрать мячи, размер, котик/цветные мячи,
**табличка** (текст до 300 символов, время показа 3-300 с, жёлтая/красная/белая), убрать все таблички.
Табличку получатель может перетащить мышью и закрыть крестиком.

## Безопасность

* Программа исполняет **только фиксированный список команд** (мячи, размер, вид, табличка). Запуска программ,
  доступа к файлам, экрану, клавиатуре, буферу обмена нет и быть не должно.
* Команды отправляет только тот, кто знает `ADMIN_TOKEN`. После 10 неверных попыток с одного адреса сервер блокирует
  попытки на 10 минут. Не публикуй пароль и ключ комнаты открыто.
* Ключ комнаты работает как «пароль на получение»: кто его знает, может *слушать* команды (и ничего больше).
* Включай удалённое управление только на тех ПК, где владелец согласен. В программе оно по умолчанию **выключено**.

## Протокол (для справки)

`GET /api/poll?room=КЛЮЧ&since=N&c=ID_КЛИЕНТА` — сервер держит запрос до 25 с и отвечает текстом:
`L <последний номер>` и строки `C <номер>\t<команда>\t<арг1>\t<арг2>\t<арг3>`.
`POST /api/send` (заголовок `x-admin`) принимает JSON `{room, cmd, a1, a2, a3}`.
Команды: `kick`, `add`, `remove`, `size` (`up|down|reset`), `mode` (`cat|plain`), `sign` (текст, секунды, `note|alert|plain`), `clearsign`.
